Cost of Looking's material is not simulated. Every value in the piece — duration_api_ms, ttft_ms, input/output/cache-read/cache-creation token counts, cost_usd — is telemetry logged from the actual Claude API calls made while this piece was built, pulled from the raw usage JSON the API returns for each request.

Before any of that data existed, a detector was frozen: three rules — latency over 4000ms, first retry (no baseline required, fires on first occurrence), and cache-creation deviation outside a 4844–4853 token band — calibrated on eight throwaway calls in which zero retries occurred. The order matters. A detector written after seeing the session's real numbers could always be tuned, consciously or not, to flag exactly what happened and nothing else — a diagnosis fitted to its own patient. Freezing the thresholds first forecloses that: whatever the live build run produces, the rules cannot bend to meet it.

The calibration run also surfaced something the interface never shows: each visible Sonnet call quietly spawns a second, cheaper Haiku call (~900 input tokens) to generate a session title — a cost incurred, and hidden, by default. The piece treats that as found material, not commentary.
